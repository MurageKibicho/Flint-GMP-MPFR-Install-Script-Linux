# Flint-GMP-MPFR-Install-Script-Linux
Bash installation script to get FLINT, GMP and MPFR running for some indecent computations lol

## Getting Started

### Local Installation
1. Check Download.sh and ensure you're working with your desired library versions.
2. Clone the repo, cd into the folder.
3. Make Download.sh executable, run Download.sh and make executable
```
!chmod +x Download.sh

!./Download.sh

!source ~/.bashrc 2>/dev/null

!source ~/.zshrc 2>/dev/null
```

### Google Colab installation
You can use the provided Jupyter Notebook to get it running on Colab
